# Security Policy

## Reporting a vulnerability

Email **security@vibeisland.app** with what you observed and the Vibe Island version
you saw it in. A proof of concept or the exact command output helps, but is not
required — a clear description is enough to start.

I read every report myself and aim to reply within 48 hours.

Please report security and privacy issues by email rather than in a public issue,
so a fix can ship before the details are public. Once it is fixed, the release
notes will describe what changed and name the affected versions, and I will credit
you unless you would rather stay anonymous.

This policy is also published at
[vibeisland.app/.well-known/security.txt](https://vibeisland.app/.well-known/security.txt).
